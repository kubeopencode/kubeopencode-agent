# Postmortem Template

Use this template when writing a new incident retrospective.

```markdown
# Postmortem: YYYY-MM-DD - Title

## Summary
- Duration: HH:MM - HH:MM (UTC)
- Impact: What was affected and for how long
- Severity: P0/P1/P2

## Timeline
- HH:MM - Event detected
- HH:MM - Root cause identified
- HH:MM - Mitigation applied
- HH:MM - Full resolution

## Root Cause Analysis (5 Whys)

## Impact Assessment

## Action Items
| Item | Owner | Due | Status |
|------|-------|-----|--------|

## Lessons Learned
```
